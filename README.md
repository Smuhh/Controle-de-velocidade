
# Controle de Velocidade

Programa desenvolvido em Java que recebe uma velocidade informada pelo usuário e verifica se o robô está em movimento.

## Tecnologias utilizadas

- Java
- Scanner
- if/else
- boolean
- Variáveis do tipo double

## Funcionamento

O programa solicita ao usuário uma velocidade. 
Se a velocidade for maior que 0, o programa informa que o robô está se movendo.
Caso contrário, informa que o robô está parado.
